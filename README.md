# Math Efficiency

**让抽象的数学变得可视、可感、可理解**

一款面向大学生的数学学习桌面应用，覆盖高等数学、线性代数、概率论与数理统计三门核心课程，以交互式动态演示为核心特色，辅以系统化的知识梳理与考试易错辨析。

## 为什么做这个工具

高等数学中有大量概念依赖几何直觉——极限的逼近过程、导数的切线含义、积分的面积本质——但传统教材只能用静态图文呈现。Math Efficiency 的出发点很简单：**把这些"动态过程"真正动起来**，让你拖一拖滑块、点一点播放，亲眼看到参数变化如何影响函数形态。

在此基础上，我们进一步梳理了定义定理、公式速查、推导过程和考试易错点，形成一个完整的学习闭环。

## 功能模块

### 1. 知识点学习 — 五维展示 + 动态演示

这是应用的核心模块。每个知识点以五个维度展开：

| 维度 | 内容 |
|------|------|
| **动态演示** | Canvas 2D 绘图，滑块调参，动画播放，对比模式 |
| **概念讲解** | 核心思想 → 严格定义 → 性质定理 → 典型例题 → 常见误区 |
| **拓展延伸** | 二级结论、关联概念、进阶视角 |
| **应用实例** | 物理建模、工程应用中的实际场景 |
| **方法总结** | 解题步骤化、流程化 |

**学科覆盖：**

- **高等数学上册**：函数与极限、导数与微分、积分
- **高等数学下册**：向量代数与空间解析几何、多元函数微分法、多元函数积分学、无穷级数、微分方程
- **线性代数**：行列式、矩阵
- **概率论与数理统计**：随机事件和概率、一维随机变量及其分布、二维随机变量及其分布、数字特征、大数定律与中心极限定理、数理统计基本概念、参数估计、假设检验

共计 **18 个章节、82 个知识点**，每个知识点均配备可交互的 Canvas 动态演示。

---

### 2. 概念定理 — 严格定义 + 白话解释

将数学中的核心概念和定理单独拎出来，给出：
- 严格的数学定义（ε-δ 语言等）
- 白话解释，降低理解门槛
- 相关定理的完整陈述
- 概率论与数理统计章节已覆盖

---

### 3. 公式手册 — 快速查阅，分类清晰

覆盖高数、线代、概率统计三大科的常用公式，按章节分类：

- 极限与连续、导数表、积分表、微分定理、无穷级数、微分方程
- 二重积分、三重积分、曲线积分、曲面积分
- 向量代数、多元微分、空间解析几何
- 行列式、矩阵、线性方程组、二次型、线性空间
- 随机事件和概率、一维/二维随机变量、数字特征、大数定律与中心极限定理、数理统计基本概念、参数估计、假设检验

共 **30 个分类、170+ 条公式**，支持搜索与收藏，每条公式附带说明与示例。

---

### 4. 公式推导 — 知其然，更知其所以然

不是只给你结论，而是带你走一遍推导过程：

- 每个推导项包含：引入动机 → 完整推导步骤 → 结论 → 应用举例
- KaTeX 实时渲染数学公式，排版清晰
- **24 个章节、84 个推导项**，覆盖：
  - 高数上册：重要极限、导数法则、中值定理、积分方法等
  - 高数下册：向量运算、多元微分、多元积分、级数展开、微分方程求解等
  - 概率统计：贝叶斯公式推导、分布函数性质证明、期望方差公式、极大似然估计、假设检验原理等
  - 线性代数：行列式展开、矩阵求逆、线性方程组求解、特征值与特征向量、二次型标准化、Schmidt 正交化等

---

### 5. 沧海遗珠 — 考试最容易忽略的那些点

这是从大量考研真题和教学经验中提炼出的易错、易混、易漏知识点集合，每条包含：
- **易错问题**：以判断题形式呈现
- **典型错误**：学生最容易犯的误解
- **正确理解**：准确答案 + 详细解释
- **相关公式**：LaTeX 渲染的数学公式
- **考试提醒**：实战注意事项

支持按类型（易混淆 / 陷阱 / 细节 / 对比）和严重程度筛选，支持收藏功能。

**内容规模：335 条**，覆盖 19 个章节：
- 概率统计 8 章（随机事件和概率、一维/二维随机变量、数字特征、大数定律与中心极限定理、数理统计基本概念、参数估计、假设检验）
- 线性代数 6 章（行列式、矩阵、线性方程组、特征值与特征向量、二次型、向量与向量空间）
- 高数上册 5 章（函数与极限、导数与微分、微分中值定理与导数应用、不定积分、定积分）
- 高数下册 4 章（向量代数与空间解析几何、多元函数微分法、多元函数积分学、微分方程）

---

### 6. 题库 — 专项训练

收录历年考研数学真题及模拟题，支持按年份、章节、题型筛选，题目内嵌 KaTeX 公式渲染。

## 技术架构

| 层次 | 技术选型 |
|------|---------|
| 框架 | React 18 + TypeScript 5.3 |
| 构建 | Vite 5 |
| 桌面端 | Electron 28 |
| 状态管理 | Zustand |
| 数学渲染 | KaTeX |
| 图标 | Lucide React（SVG） |
| 动态演示 | Canvas 2D API |
| 打包 | electron-builder（NSIS 安装包） |

关键工程实践：
- 大组件懒加载（React.lazy + Suspense），减少首屏体积
- Canvas 绘图函数与滑块参数联动，实现实时交互
- Unicode 数学符号自动识别与 LaTeX 转换
- localStorage 持久化收藏与配置数据

## 安装与运行

### 环境要求

- Node.js >= 18
- npm >= 9

### 开发模式

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 启动 Electron 开发模式
npm run electron:dev
```

### 构建打包

```bash
# 构建并生成安装包
npm run electron:build
```

生成的安装包位于 `C:/Users/<用户名>/Desktop/安装包` 目录下（可在 package.json 中修改输出路径）。
